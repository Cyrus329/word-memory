## 手机背词模式

- 原手机首页新增“手机背词”入口，打开后进入一屏一词的专注界面。
- 每次只显示一个单词或短语，释义默认隐藏，点击卡片后再查看答案。
- 可选择“忘了 / 模糊 / 记得”三档评分，评分继续复用原有学习进度和复习安排。
- 左右滑动只负责前后导航，不会误记学习结果。
- 原听写模式的 Enter 二次确认、原手机首页和电脑端布局保持不变。
